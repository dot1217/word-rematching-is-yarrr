🏫 반 끝말잇기 대전

SCHOOL BATTLE

학교를 검색하고 학년·반과 닉네임을 설정해. 같은 방식으로 입장한 다른 학교·반과 1대1 또는 4인 대전을 할 수 있어.

검색어가 학교 이름으로 시작하거나 이름 중간에 포함되는 학교를 추천해.

학교 데이터 가져오기

NEIS · CSV

전국 학교 전체 검색을 사용하려면 나이스 학교기본정보 API 키를 입력하거나, 공식 CSV를 가져와 줘. 처음 제공되는 추천 목록은 운정 주변 예시 학교야.

나이스 인증키는 나이스 개발자 가이드에서 발급할 수 있어. 공식 학교정보 CSV는 공공데이터포털 전국초중고등학교 정보에서 받을 수 있어.

관리자 패널

게임 규칙을 바꾸지 않는 공정한 관리·연출 명령만 사용할 수 있어.

라이트 관리자명령어 10개 · 가벼운 공격 3개

라이트 공격은 상대 입력을 아주 잠깐 방해하거나 연막 효과를 보여 줘. 하트 감소나 강제 탈락은 없어.

전체 관리자 명령어1,000개

색상·배경 연출 800개와 상대 공격 명령 200개가 있어. 공격은 실행자 다음 순서의 상대에게 적용돼.

☠️ 전체 관리자 필살기는 상대 하트를 직접 감소시킬 수 있어.
